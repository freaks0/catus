# 07. 디자인 — 하루온에서 Catus까지

> **요약** — 밤바다의 배(하루온)에서 창가의 방(Catus)까지. 다섯 꽃의 상징 체계는 "버려진 존재 둘"(달이와 선)의 이야기로 수렴했고, 달이는 네 번 다시 그려졌다. 배경부터 캐릭터까지 전부 직접 그린 에셋이다.

외부 디자이너 없이 피그마로 직접 진행한 디자인 과정의 기록이다. 컨셉은 한 번 완전히 뒤집혔고, 캐릭터는 여러 번 다시 그려졌다. 그 흔적이 세 개의 피그마 파일에 남아 있다.

## 1막. 하루온 — 밤바다를 항해하는 배, 그리고 꽃

첫 번째 컨셉의 이름은 "하루온"이었다. 은유 체계는 이렇다 — **나의 내면은 배, 성장시킬 무언가는 식물(꽃·열매), 하루하루는 항해.** 사용자는 밤바다 위 자신의 배에서 꽃을 키우며 내면을 돌본다.

## 2막. 전환 — 다섯 송이의 꽃 대신, 버려진 선인장 하나

하루온 컨셉은 폐기됐다. 파일에 남은 실험 흔적(이미지 생성 모델 비교 리서치, "식물 일관성 프롬프트" 실험)이 보여주듯 사실적 일러스트 톤은 AI 생성 이미지의 일관성 유지가 어려웠고, 다섯 가지 꽃의 상징 체계는 관리해야 할 세계관이 너무 많았다.

재편의 방향은 "여러 식물의 상징"을 **버려진 존재 둘의 이야기**로 수렴시키는 것 — 12간지에서 탈락해 밤을 택한 고양이 달이, 뾰족하다는 이유로 버려진 선인장 선 (→ [01. 기획 - 네이밍과 세계관](01-planning.md)). 톤도 사실적 일러스트에서 **납작하고 따뜻한 파스텔**로 바뀌었다. 사용자 인터뷰의 소수 의견이 이 방향을 지지했다: *"너무 현실적이거나 차가운 그림보다는 감정의 온도를 담은 표현이 더 와닿습니다."*

### 달이의 변천

고양이 캐릭터도 한 번에 나오지 않았다. 주황 고양이가 선인장을 안고 있던 첫 로고에서 시작해, 픽셀풍 간이 시안("MyCat")을 지나, 세계관(밤을 택한 검은 고양이)이 잡히며 검은 고양이로 다시 그렸고, 이후에도 눈매·비율을 미세하게 조정하는 반복을 거쳤다:

|:---:|:---:|:---:|:---:|
| 첫 로고 시안 — 주황 고양이와 선인장 | 검은 고양이 전환 — 날카로운 눈매 | 둥근 링 모양 눈 버전 | 최종 달이 (실제 앱 에셋) — 아몬드형 눈에 빛 반사, 갈색 코, 수염 |

날카로움 → 동그란 링 → 빛이 담긴 아몬드형 눈. 특히 마지막 단계에서 눈에 흰 하이라이트가 들어가며 "밤에도 반짝이는 눈"이라는 달이다움이 완성됐다.

## 3막. Catus 디자인 확정

최종 확정된 방 씬. 배경 숲, 창틀, 선인장 둘, 공책, 종이비행기, 달이 — 모든 오브젝트를 직접 그려서 한 장면으로 합성했고, **낮과 밤 두 벌**로 만들었다. 밤 씬은 달이가 일기를 가져다주는 시간의 얼굴이자 다크모드의 배경이다. 구현은 이 씬을 거의 그대로 재현했다:

### UX 디테일은 문장으로 먼저 정의됐다

응원 메시지의 표현 방식은 그림보다 문장이 먼저였다. 피그마에 남아 있는 당시의 정의:

> "다른 사용자의 그림일기가 날아온 걸 **종이비행기**로 표현"
> "다른 사용자가 나의 그림일기에 메시지를 보내줬을 때 일기장에 **말풍선**으로 표시"

구현에서는 이 설정이 두 갈래로 다듬어졌다 — **타인의 떠도는 일기**는 달이를 세 번 쓰다듬으면 달이가 물어다 주고(세계관 문서의 "달이가 물고 온다"가 채택됨), **응원 메시지**가 도착하면 종이비행기가 창가로 날아든다. 아래는 응원 메시지함 작업 화면 — **왼쪽**이 확정 시안(노트 위 발자국, 화면 아래에서 빼꼼 내다보는 달이와 선), **오른쪽**은 그보다 이른 픽셀풍 탐색 시안(MyCat)이다:

## 설계 체계의 흔적

와이어프레임 외에도 서비스 전체를 설계한 산출물이 함께 남아 있다 — 회원가입 퍼널 정의, 온보딩 시나리오(감정분석 온보딩 1~8), 그리고 가입부터 배치 일기 생성·공개 범위·구독 모델(월 4,900~9,900원 가설)까지 그린 사용자 흐름도.

흐름도의 뼈대(가입 → 성향 분석 → 자유 대화 → 지정 시간 배치 생성 → 공개 선택 → 익명 응원)는 실제 구현과 거의 일치한다. 구독·채팅 횟수 제한 같은 수익화 요소는 구현에서 제외하고 로드맵으로 남겼다.
