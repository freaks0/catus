# Catus

고양이 캐릭터 달이와 나눈 대화를 LLM이 그날의 그림일기로 바꿔 주는 감정 기록 웹 서비스입니다.
기획, 사용자 인터뷰, 캐릭터 디자인, 백엔드와 LLM 프롬프트 설계, 배포와 운영을 혼자 했습니다.

| | |
|---|---|
| 대상 | 아직 고립되지는 않았지만 힘든 이야기를 꺼낼 곳이 없는 20대 |
| 문제 | 고립 청년 지원 제도는 당사자가 찾아와야 시작되고, 이미 고립된 사람은 찾아오지 않습니다 |
| 접근 | 상담 대신 매일 쓰는 가벼운 기록 도구로 고립 이전의 일상에 들어갑니다. 쓰기 부담을 없애려고 대화가 곧 일기가 되게 했습니다 |
| 결과 | 시스템 프롬프트를 14,043자에서 3,666자로 줄여 채팅 응답 6.8초를 1.5초로 단축. 일기 본문과 삽화 프롬프트를 LLM 1회 호출로 생성. 무료 인프라에서 일부 사용자 테스트 중 |
| 스택 | Java 21 · Spring Boot 3.2 · PostgreSQL · Gemini API · React 19 |

## 핵심 결정 세 가지

**1. 위로는 AI가 아니라 사람이 보내게 했습니다.**
20대 7명 인터뷰에서 가장 많이 나온 답은 "약한 모습을 보이기 싫다"였고, "AI 위로는 정신승리"라는 회의론도 있었습니다. 그래서 커뮤니티와 친구 기능을 빼고, 공개에 동의한 일기에 익명의 사용자가 단방향으로 응원을 보내는 구조를 만들었습니다. [사용자 리서치](06-user-research.md)

**2. LLM이 하루를 지어내지 못하게 했습니다.**
짧은 대화에서 "위로를 얻은 기분이었다"처럼 없던 감정이 일기에 생성됐습니다. 대화에 실제로 나온 사건과 감정만 쓰는 규칙을 프롬프트에 두고, 대화가 없는 날은 생성하지 않습니다. [기획](01-planning.md)

**3. 프롬프트를 코드처럼 관리했습니다.**
인격, 안전 규칙, 용도별 규칙을 파일로 나눠 조립합니다. 기능을 더할수록 응답이 느려졌을 때, 이 구조 덕에 파일 단위로 측정하고 규칙을 보존한 채 압축할 수 있었습니다. [시스템 설계](03-architecture.md) · [트러블슈팅](04-troubleshooting.md)
